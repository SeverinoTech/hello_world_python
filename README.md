# Hello World Python

> Código Simples como portifólio exemplo para demonstrar trabalho com Python.

## Sobre o Projeto

Este repositório contém um programa simples em Python que exibe a mensagem "Hello World".

## Tecnolçogias Utilizadas

```
- Python3+
- PEP8 para boas práticas
- Git e GitHub para versionamento
```

## Código

```python
"""
Script simples de Hello World para portifólio
"""

def main():
    "Função principal que imprime uma mensagem de boas-vindas."
    print("Hello World!")

if __name__ == "__main__":
    main()
````

## Como Executar

1. Clone deste repositório:
````
sudo git clone https://github.com/SeverinoTech/hello_world_python.git
````

2. Acessar o diretório do projeto
````
cd hello_world_python/
````

3. Acessar o diretório do projeto
````
python main.py
````
